# Paradise Nursery

Paradise Nursery is a React-based online houseplant shopping application.

The application allows users to:

- Browse houseplants grouped into multiple categories
- View plant images, names, and prices
- Add plants to a shopping cart
- Increase and decrease plant quantities
- Remove plants from the cart
- View the total number of plants
- View the total shopping cart cost
- Continue shopping from the cart
- Access a checkout option

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- Vite

## Pages

### Landing Page
Introduces Paradise Nursery and provides a Get Started button.

### Product Listing
Displays plants grouped into categories with Add to Cart functionality.

### Shopping Cart
Displays selected plants, quantities, item totals, and overall cart total.
